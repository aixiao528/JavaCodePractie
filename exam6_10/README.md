# 基于 MySQL 的学生在线选课系统

本项目是一个标准 Java 控制台项目，使用 JDBC 连接 MySQL，实现了学生选课、退课、转课、教务批量选课、事务回滚演示和多表联查等核心功能。

## 1. 项目结构

```text
exam6_10
|-- db.properties.example
|-- pom.xml
|-- build.ps1
|-- run.ps1
|-- sql
|   |-- schema.sql
|   `-- data.sql
|-- docs
|   `-- report.md
`-- src
    `-- main
        `-- java
            `-- com.exam.course
```

## 2. 功能清单

- 单条选课：根据学生 ID 和课程 ID 完成选课
- 学生退课：删除选课记录并回收课程名额
- 学生转课：把某学生已选课程转让给另一名学生，并用手动事务保证整体提交
- 异常回滚演示：模拟转课给其他同学时中途失败并整体回滚
- 教务批量选课：支持指定多个学生批量选同一门课程
- 课程缓存：缓存课程列表，减轻重复查询数据库的压力
- 多表联查：查询学生所选课程名称、学分和成绩

## 3. 数据库准备

1. 先执行 `sql/schema.sql`
2. 再执行 `sql/data.sql`
3. 复制 `db.properties.example` 为 `db.properties`
4. 根据本机 MySQL 配置修改账号、密码和连接串

## 4. 驱动说明

本项目源码基于 JDBC 标准接口编写，`pom.xml` 中已声明 MySQL Connector/J 依赖。

如果你使用 IntelliJ IDEA 导入项目，可以直接识别 `pom.xml`。

如果你使用命令行运行，请确保 `lib` 目录下存在 MySQL JDBC 驱动 jar，例如：

```text
lib/mysql-connector-j-9.7.0.jar
```

## 6. 控制台菜单

```text
1. 查看课程列表（缓存）
2. 学生单条选课
3. 学生退课
4. 学生转课给其他同学（正常事务）
5. 教务批量选课
6. 查询学生全部已选课程
7. 转课给其他同学回滚演示（模拟异常）
8. 手动刷新课程缓存
0. 退出系统
```

## 7. 推荐演示顺序

1. 查看课程列表
2. 使用学生 `1005` 选择课程 `2004`
3. 使用学生 `1005` 退掉课程 `2004`
4. 使用学生 `1001` 把课程 `2001` 转给学生 `1005`
5. 使用课程 `2002` 对学生 `1005,1006` 进行批量选课
6. 查询学生 `1001` 或 `1005` 的选课详情
7. 使用“转课回滚演示”展示插入接收学生后异常触发时的数据回滚
